# 产品范围

## 定位

OlistOps Agent 面向中小电商运营负责人和数据分析人员，使用 Olist 历史匿名数据完成履约、卖家表现和客户体验分析。它不是泛化办公助手，也不宣称训练了企业大模型。

## 必须支持

- 配送异常根因分析。
- 低分评论证据分析。
- 指定卖家经营诊断。
- 确定性指标、知识引用、证据门控和安全拒答。
- 本地与云端模型 Provider 可切换。
- SSE、Trace、评测和人工审批边界。

## 范围外

- 实时订单同步和真实 ERP 写入。
- 真实客户联系或自动发送邮件。
- 库存预测、仓库调度和补货优化。
- 从匿名数据推断真实个人身份。
- 无限 ReAct、多 Agent 群聊或自主执行任意命令。

## 成功标准

MVP 必须在不依赖 LLM 的情况下正确计算演示任务所需结构化结果。模型只负责解释与生成；模型不可用或输出失败时，工作流应使用固定模板完成或基于证据拒答。
