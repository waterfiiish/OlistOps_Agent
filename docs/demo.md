# 演示脚本

## 任务 A：配送异常

输入：

```text
分析 2018 年 7 月的配送表现，找出延期率最高且订单量不少于 20
的卖家和商品类别，比较延期订单与按时订单的平均评分，并给出改进建议。
```

展示：

1. Web 状态卡中的 PostgreSQL、pgvector 和模型 Profile。
2. SSE 时间线中的真实节点和三个只读工具。
3. 卖家/类别的订单量、合格分母、延期订单、延期率和评分。
4. 知识引用、事实/推断/建议和限制。
5. `/api/v1/runs/{run_id}/trace` 中的参数、结果摘要与模型回退。

## 预期 Gold

在官方 Olist 数据集上，2018 年 7 月且订单量不少于 20 的卖家排名第一项应为：

- seller_id：`06a2c3af7b3aee5d69171b0e14f0ee87`
- 订单量：71
- 延期订单：30
- 延期率：0.42254

这些数字由 MART 查询重复计算，不由模型生成。
