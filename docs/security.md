# 安全设计

## Prompt Injection

- 系统指令、用户输入与知识文档分层。
- 检索内容是数据，不能新增工具、提升权限或取消审批。
- 中英文注入模式会被标记，命中片段从生成证据中脱敏。

## 工具与代理权限

| 等级 | 行为 | 当前策略 |
|---|---|---|
| READ | MART 查询、知识检索、Trace | 允许 |
| GENERATE | 草稿、临时图表 | 允许但标记草稿 |
| PERSIST | 正式报告保存 | 必须审批；当前工作流不直接执行 |
| EXTERNAL_WRITE | 邮件、真实系统修改 | MVP 禁用 |

Tool Registry 在调用前使用 Pydantic Schema 校验参数。未知工具、任意 SQL 和未审批写入均被拒绝。

## 数据和日志

- `.env`、模型 Key、Kaggle 凭据和原始 CSV 不进入 Git。
- 评论只返回最长 280 字符的匿名摘录。
- Trace 默认保存输入摘要和哈希，不保存密钥。
- 报告必须声明历史数据范围、相关性和因果限制。

## 文件与资源

- Workspace 路径解析后必须位于配置根目录。
- 单次运行最多 10 个节点、8 次工具调用、120 秒、500 行结果。
- 上传文件默认限制 20MB；正式上传接口进入后还需增加 MIME 和内容哈希检查。
